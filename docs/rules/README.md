# Game Rules

One summary of the official rules per set that has a rulesheet, written in our own words as a reference for implementing the app.

- [classic.md](classic.md): the base game, Classic (2nd edition).
- [upgrade.md](upgrade.md): Meaning of Life, Techlings, Dinolings, Mythlings and Multicolor.
- [imaginary-ends.md](imaginary-ends.md): Deeplings, Magical Merchants, Glitterlings, Moonlings and Fuzelings.
- [legends-of-enderas.md](legends-of-enderas.md): Techlings, Mythlings, Dinolings, Fuzelings and Treasures.
- [castle-glass.md](castle-glass.md): trait classes.
- [overlush.md](overlush.md): how to build a game from the Overlush collection.

Sets without a rulesheet (Mokoko Village, Nightflower Island, Shadow Puppets, special cards) have no file here.

## Which Source Wins

- The rulesheet in [`assets/doomlings/rules`](../../assets/doomlings/rules) and its transcription (`<set>.md`, same folder) are authoritative. When a summary here disagrees with them, they win.
- Within a game, ages come first, then traits, then the rulesheets ([classic.md](classic.md#discard-pile-and-disputes)). The expansion rulesheets add their own conflicts: trinket powers beat ages and trait effects ([imaginary-ends.md](imaginary-ends.md)).
- Where a rulesheet leaves something open, the summary says so as an open question instead of filling it in.
