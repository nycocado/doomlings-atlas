# Game Rules (Castle Glass)

Summary of the official rules for the Doomlings Castle Glass expansion, written in our own words as a reference for implementing the app. It adds to [Classic](classic.md). The official rulesheet is authoritative; if this file disagrees with it, the rulesheet wins.

Source: [rulesheet](../../assets/doomlings/rules/castle-glass.pdf) and its [transcription](../../assets/doomlings/rules/castle-glass.md).

## Components

30 traits plus 7 dominants, 2 ages and 1 catastrophe. The expansion adds trait classes, with three new ones: Shells, Coral and Fish. A trait's class is at the bottom of the card. Some class cards are labelled Curious (e.g. Curious Shell) or Exotic (e.g. Exotic Fish), and are worth more.

## Scoring

After counting the Drop of Life bonuses at the end of the game, sort your class cards.

- If you have 2 or more cards from the same class, each card in that class scores extra points: +1 for a class card, +2 for a Curious one, +3 for an Exotic one.
- A lone card of a class scores nothing, as in the rulesheet's first example.

Examples from the rulesheet: 2 cards of different classes score 0; Shell, Shell and a Coral score 2 (the Coral is alone); Shell, Curious Shell and Exotic Shell score 6; Coral and Curious Coral plus Shell and Exotic Shell score 7.
