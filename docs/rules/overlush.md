# Game Rules (Overlush)

Summary of the official rules for the Doomlings Overlush collection, written in our own words as a reference for implementing the app. It adds to [Classic](classic.md). The official rulesheet is authoritative; if this file disagrees with it, the rulesheet wins.

Source: [rulesheet](../../assets/doomlings/rules/overlush.pdf) and its [transcription](../../assets/doomlings/rules/overlush.md).

Overlush adds no rules of its own. Its rulesheet only explains how to recreate the Mystery Expansion experience.

## Setup

1. Separate the basic traits, dominants, ages and catastrophes into 4 piles.
2. Shuffle each pile.
3. Draw 8 ages, 4 catastrophes, 8 dominants and 40 traits.
4. Add these cards to the mix and set up the game as normal.

The rulesheet also says the game may be customized, for example by drafting 15 dominants and playing with many Classic ages.
